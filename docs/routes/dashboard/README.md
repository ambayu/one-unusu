# Dashboard SSO — Overview

Rute `/dashboard` merupakan pintu gerbang utama setelah civitas login ke ONE UNUSU. Di rute ini, pengguna dapat melihat ringkasan identitas dan meluncurkan aplikasi-aplikasi kampus tanpa perlu memasukkan password kembali.

---

## Fitur Utama
- **Identity Banner**: Menyapa civitas dan menampilkan role, NIM/NIDN, dan prodi.
- **SSO v2 Ticket Status**: Memperlihatkan bahwa sesi otentikasi terpusat sedang aktif.
- **Katalog Aplikasi Terintegrasi**: Kartu aplikasi yang dapat dibuka secara instan.
- **Direktori Layanan Publik**: Tautan ke website resmi, PMB online, SIAKAD, dan prodi.
