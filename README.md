# ONE UNUSU

Integrated Digital Campus
Universitas Nahdlatul Ulama Sumatera Utara

## Technology Stack
- Frontend: Next.js 16 + TypeScript + Tailwind CSS
- Backend: Laravel (planned)
- Database: MySQL
- SSO: Keycloak (planned)
- Production Deployment: Docker Compose

## Development
Frontend:
cd frontend
npm install
npm run dev

## Deployment
Ubuntu Server + Docker Compose
